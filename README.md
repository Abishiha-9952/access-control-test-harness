# access-control-test-harness
A generic and reusable test harness for detecting access control vulnerabilities in REST APIs.

## Project Overview

The Access Control Test Harness is a generic and reusable security testing framework designed to identify access control vulnerabilities in REST APIs. It helps security testers and developers verify whether API resources and actions are properly protected from unauthorized access.

## Project Goals

- Detect broken access control vulnerabilities in REST APIs.
- Provide a reusable testing approach for different API endpoints.
- Verify whether users can access resources or perform actions without proper authorization.
- Generate clear test results that can help developers identify and fix security issues.
